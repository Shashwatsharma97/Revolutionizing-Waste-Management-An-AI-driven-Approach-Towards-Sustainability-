# ♻️ Revolutionizing Waste Management: An AI-Driven Approach to Food Waste Prediction

## 📌 Project Overview

Food waste is one of the most significant global challenges affecting sustainability, resource utilization, and environmental health. This project leverages Machine Learning techniques to analyze food consumption patterns and predict food wastage in event-based environments.

The objective is to identify the factors contributing to food waste and build predictive models that can help organizations, event planners, restaurants, and institutions optimize food preparation and reduce unnecessary waste.

---

# 🎯 Problem Statement

Large quantities of food are wasted due to inaccurate demand estimation, inefficient storage conditions, and poor planning.

This project aims to:

* Predict food wastage using historical event data.
* Identify key factors influencing food waste.
* Improve resource planning and food management.
* Support sustainable waste reduction strategies through AI-driven insights.

---

# 📊 Dataset Features

The dataset contains various event and food management attributes including:

| Feature             | Description                    |
| ------------------- | ------------------------------ |
| Number of Guests    | Total attendees at an event    |
| Quantity of Food    | Amount of food prepared        |
| Type of Food        | Category of food served        |
| Event Type          | Type of event conducted        |
| Storage Conditions  | Food storage environment       |
| Purchase History    | Historical purchasing patterns |
| Seasonality         | Seasonal impact factors        |
| Pricing             | Food pricing information       |
| Wastage Food Amount | Target variable                |
